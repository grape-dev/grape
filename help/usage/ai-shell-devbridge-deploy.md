# 11. AI Shell + DevBridge 快速部署

> 目标：30 分钟内跑通「提交一个部署需求 → AI 自动部署 → 拿到公网链接」的完整体验。
> 适合首次体验 Grape 部署能力的用户，无需准备任何服务器。

## 整体流程

```
配置 AK/SK → 创建 AI DevSpace 设备 → 设备接入（AI Shell 引擎上线）
→ 场景中心应用「Hello World 部署」场景 → 需求中心下部署需求
→ 流水线执行 → SRE 通过 DevBridge 部署 → 返回公网链接
```

## 1. 配置华为云 AK/SK

DevBridge 公网访问依赖华为云凭据，先在平台完成配置。

1. 登录 Grape 平台，进入 **账户设置 → 凭据**（Credentials）页签。
2. 填写华为云 **Access Key Id（AK）** 与 **Secret Access Key（SK）**，保存。
   - 获取入口：[华为云控制台 → 我的凭证 → 访问密钥](https://console.huaweicloud.com/iam/?locale=zh-cn#/mine/accessKey)
   - 没有密钥就点「新增访问密钥」，下载的 CSV 文件里包含 AK/SK。
3. 保存成功后凭据仅对你本人生效（存储加密，页面回显掩码）。

> 💡 AK/SK 只用于 SRE 部署环节申请临时凭据（STS），不会下发给 Coding/QA 等其他 Agent。

## 2. 创建 AI DevSpace 设备

AI DevSpace 是华为云云开发环境，创建后自动注册为 Grape 的 Worker 设备，无需自备机器。

1. 进入 **运行时** 页面，切换到 **AI DevSpace** 标签。
2. 点击右上角 **创建** 按钮。
3. 等待环境状态变为 **运行中**（首次创建约 1-3 分钟；账号首次使用需签署 CodeArts 开发环境服务协议，页面会给出指引链接）。
4. 环境就绪后，安装脚本会自动执行：设备以你的账号注册为个人级（user scope）Worker，并自动注册其内置引擎。

> 💡 数量上限与计费遵循华为云 CodeArts 开发环境服务的账号配额；不再使用时可在同一页面停止/删除环境。

## 3. 确认 AI Shell 引擎已接入

设备接入后，它携带的引擎会出现在平台引擎列表中。

1. 进入 **运行时 → 引擎** 列表（或系统监控）。
2. 找到你的 DevSpace 设备名下的 **AI Shell** 引擎，确认状态为 **在线**。
3. 在线即代表该引擎已可承接 SRE 任务（DevBridge 部署由 AI Shell 引擎执行）。

> 💡 引擎 15 秒内自动上报心跳；若长时间不在线，回到 AI DevSpace 页面确认环境处于运行中状态。

## 4. 在场景中心应用「Hello World 部署」场景

1. 进入 **场景中心**（Scene Market）。
2. 找到 **Hello World 部署** 场景——从需求到部署的完整流水线演示，SRE 环节使用华为云 DevBridge 部署技能，适合首次体验。
3. 点击 **应用**，选择目标仓库（示例模板推荐 `hello-flask`，也可以用你自己的 Web 项目仓库）。
4. 应用后该仓库的流水线即按此场景执行：VOD → Issue → Coding → QA → SRE。

> 💡 应用场景只影响当前仓库；其他仓库不受影响，可随时在场景中心更换。

## 5. 在需求中心下发部署需求

1. 进入 **需求中心**（Issues），选择已应用场景的仓库。
2. 新建一个需求，标题示例：

   > 帮我部署本项目，并可公网访问

3. 提交后流水线自动启动：
   - **VOD**：分析需求，路由为部署类任务
   - **Issue**：细化执行方案
   - **Coding**：准备项目（如需构建则完成构建）
   - **QA**：快速校验
   - **SRE**：AI Shell 引擎执行 DevBridge 部署——拉取代码、识别项目类型（Flask / Node.js / 静态页面）、安装依赖、启动服务、建立公网隧道
4. 每个阶段可在任务详情中查看执行过程与日志。

## 6. 获取公网链接

SRE 阶段执行完成后，任务结果中会返回一个 **公网访问链接**（形如 `https://xxxx.devbridge-s2.hwtunnel.com`）。

- 点击链接即可在浏览器中访问并体验部署成果。
- 链接有效期以隧道配置为准，到期后可重新下发部署需求再次获取。

## 常见问题

| 问题 | 处理 |
|------|------|
| 创建 DevSpace 提示未签署协议 | 按页面指引签署 CodeArts 开发环境服务协议后重试 |
| AI Shell 引擎不在线 | 确认 DevSpace 环境运行中；等待 15 秒心跳刷新 |
| SRE 阶段失败提示凭据问题 | 回到账户设置检查 AK/SK 是否有效、是否有足够权限 |
| 公网链接打不开 | 链接可能已过期，重新下发一次部署需求 |
