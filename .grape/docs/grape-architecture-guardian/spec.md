- 审查结论输出模板升级：按 4 级别归类统计 + 合入建议

## Technical Approach

### 方案概述
在现有 grape-architecture-guardian 技能的规则文件（references/grape-architecture-rules.md）中融入 2.0 分级体系与 16 条新规则，同步更新 SKILL.md 审查流程与结论模板，并按需扩展配套只读脚本（repo_inventory / magic_number_audit / grape_constraint_check）覆盖静态可检项。

### 实现路径
1. references/grape-architecture-rules.md：写入 4 级判定体系 + 16 条规则（A1-A9/B1-B2/C1-C3/D1-D2），每条含级别标注与证据要求，并与既有 7 Gate/数值证据门禁融合（无规则丢失）
2. SKILL.md：审查结论输出改为按 4 级别归类统计（如 0 BLOCKED / N Critical / N Medium / N Informational）+ 对应合入建议；版本号 bump 至 1.x.0
3. scripts/：A6 表名（grape_t_xxx / grape_admin_t_xxx）、B1 sqlite/mysql 双模式、B2 魔鬼数字（复用 magic_number_audit.py）、D1 i18n 等静态可检项扩展，冒烟通过
4. A3/A4/A5 数值/证据类规则沿用「数值证据门禁」标签体系，禁止虚假保证
