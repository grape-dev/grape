# Spec: Issue #440 — 给 grape 开发一个架构守护 skills

> Generated by Issue Agent | Developability: ready | 2026-10-23

## Objective
- 构建 grape-architecture-guardian 架构守护技能（agent_type=qa，CLI 版）：PR 提交时按 grape-dev 组织 8 个项目（grape / grape-cli / grape-admin / grape-dsh / grape-skills / grape-template / grape-test / grape-website）的统一架构规则执行 review 模式门禁审查（7 Gate），输出带证据定位的 APPROVED / APPROVED WITH CONDITIONS / BLOCKED 结论。
- 价值：把 Grape 历史事故沉淀的架构约束固化为 PR 门禁，防回归（测试连生产库、跨组织泄露、Worker MANIFEST 漏列导致启动崩溃等）。
- 用户：grape-dev 组织 8 个项目的维护者与 QA 审查环节。
- 成功标准：技能包注册合规（name=grape-architecture-guardian、agent_type=qa、path 三段式与目录对应），7 Gate 完整、3 脚本可独立运行、报告与 Finding 契约合规、结论三态唯一。

## Scope

### In Scope
- 以用户附件技能包 grape-architecture-guardian.zip（9 文件：SKILL.md、references/×2、templates/×2、scripts/×3、agents/×1）为骨架，按 Grape 技能规范适配注册至 .grape/skills/qa/{sub_scene}/grape-architecture-guardian/（sub_scene 建议 ai-coding-review）。
- SKILL.md 保留两条不可协商规则：数值证据门禁（五源体系 + 已知数值注册表，如 uvicorn 单 worker、CLAIM_BACKSTOP_DELAY=15s、锁 TTL=60s）、禁止虚假保证（verified: code/config/doc、measured、INSUFFICIENT DATA 标签）。
- 7 个 Gate 完整（1 核心架构 / 2 组织隔离与安全 / 3 前端规范 / 4 Git 提交规范 / 5 测试规范 / 6 数值证据 / 7 架构适配性），每项三态结论（符合/不符合/不适用）+ 证据定位（文件+行号）。
- 配套 3 个只读脚本可独立运行（标准库、零依赖）：repo_inventory.py / magic_number_audit.py / grape_constraint_check.py。
- 审查报告按 templates/pr-review-report.md 输出；Finding 证据契约完整（标题/Gate/严重度/证据/问题/故障场景/修复/验证）。
- 大变更（>100 文件或 >1000 行）可委派 agents/grape-architecture-auditor.md 子 Agent 深度审计。

### Out of Scope
- 不新增代码审查算法（复用附件检查项）。
- 不修改 grape 平台运行时代码，不涉及付费资源 / 删除 / 不可逆操作。
