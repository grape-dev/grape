# Hello Skill

一个最小的 Skill 项目模板，用于快速开始一个 Skill 的创建与迭代。

## 目录结构

```
hello-skill/
├── SKILL.md            # 技能说明（名称、描述、使用方法）
├── scripts/            # 技能配套脚本
│   └── greet.py        # 示例脚本
└── README.md           # 本文件
```

## 快速开始

1. 复制本模板到你自己的仓库。
2. 修改 `SKILL.md` 中的技能名称与描述。
3. 将技能注册到 DevOps Bot（可通过 Web UI 的「DevOps Skills」页面上传）。
