# Issue Labeling Guide

## Label Prefixes

### Type
- type:bug - Bug report
- type:feature - Feature request
- type:enhancement - Enhancement
- type:documentation - Doc update
- type:question - Question

### Priority
- priority:P0 - Critical (blocker)
- priority:P1 - High (important)
- priority:P2 - Medium (nice to have)
- priority:P3 - Low (future)

### Status
- status:triaged - Reviewed and categorized
- status:in-progress - Being worked on
- status:review - Ready for review
- status:blocked - Blocked by dependency
- status:done - Completed

### Special
- vod - From Voice of Developer
- good-first-issue - For newcomers
- help-wanted - Needs community help
- quick-deploy - 应用项目仓库无 TF 模板，跳过 Coding+QA，SRE 临时编写 TF 代码直接部署

## Rules
1. Every issue must have at least one type label
2. Every issue should have a priority label
3. Remove conflicting labels
4. Use existing labels; create new ones only when necessary
