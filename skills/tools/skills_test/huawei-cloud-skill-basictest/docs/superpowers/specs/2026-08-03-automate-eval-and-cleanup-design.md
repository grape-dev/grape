# 设计文档：basictest 全自动评测 + 资源自动释放

- 日期：2026-08-03
- 状态：已确认

## 目标

1. 将 huawei-cloud-skill-basictest 改为**全自动无人值守**模式：移除所有人工确认点，触发信息全部自动推导，流程完整自动跑到底。
2. 新增**资源检测释放脚本**：评测收尾自动执行，按资源标识过滤主流华为云资源并释放，无论测试结果是否通过。

## 改动范围

### 1. 确认点移除

| 确认点 | 现状 | 改动 |
|--------|------|------|
| 触发信息收集 | 询问用户 | 自动推导：归档地址 = 被测 PR 所在仓库；资源标识 = `{用户名缩写}{YYYYMMDD}`（如 `dbq20260803`）；token 读 `GITCODE_TOKEN` env，缺失则读 `~/.gitcode_token` |
| 用例集审阅 | 交用户确认 | 直接进入实测阶段 |
| 逐条门禁 confirm | `--confirm` 手动 | `skill-eval-gate.sh` 增加 `--auto-approve` 模式：register 后自动确认（跳过 3 秒间隔），仅保留 register→complete 完整性校验与 VIOLATION 检测 |
| A-H 步骤 enter/confirm | 手动 | `run-skill-eval-gate.sh` 增加 `--auto-approve` 模式：`--enter` 后自动 `--confirm` |

### 2. 资源释放脚本 `scripts/cleanup_resources.sh`

- **扫描范围**：按资源标识过滤 ECS / EIP / 安全组 / IP 地址组 / ELB / OBS 桶等主流华为云资源（通过 hcloud CLI `List*` 查询 + 名称过滤）
- **释放逻辑**：仅释放名称含资源标识的资源，不动无关资源
- **执行时机**：阶段七归档前自动调用，无论测试通过/失败
- **产物**：输出 `资源释放报告.md`（扫描到、释放成功/失败），归档到 case-run 日期目录

### 3. SKILL.md 规范同步更新

- 移除"注意事项 1. 逐步确认（强制）"
- 新增"全自动无人值守模式"章节：触发词、自动推导规则、无确认点说明
- 新增"资源释放（强制）"章节

## 数据流

```
触发（如"测试 https://gitcode.com/.../pull/118"）
  → 自动推导 target/repo/资源标识/token
  → 准备（引擎检查/重装skill/门禁初始化）
  → 定边界 → 出正反例 → 查重归类
  → 实测（auto-approve 门禁逐条执行 + tester 流水线）
  → 归档（含资源释放报告）
  → 汇总 + 建 issue
```

## 边界

- 资源释放仅针对带资源标识的资源；未配置 hcloud 时释放脚本输出警告并跳过
- issue 创建失败不阻塞归档（记录失败原因）
- tester 流水线凭证缺失时降级为手动实测（既有逻辑保留）
