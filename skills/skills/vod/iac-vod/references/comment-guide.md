# Comment Guide

## Comment Etiquette
1. Be constructive and professional
2. Use Chinese for all issue/PR comments
3. No internal reasoning or English analysis in comments
4. No sensitive information (tokens, passwords, keys)

## Comment Types

### Positive Feedback
- Thank contributor
- Acknowledge good work
- Mark helpful comments

### Flagging Issues
- Explain why it's problematic
- Suggest improvement
- Tag relevant maintainers if needed

### No-action Response
- If no action needed, stay silent
- Do not post "no action needed" comments

## Spam/Abuse Handling
- Mark as spam if: advertising, irrelevant links, harassment
- Report to repository admin
- Do not engage with spammers
