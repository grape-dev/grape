# Grape 调度编辑器重构方案（参照 multica）

## 1. multica 调度编辑器核心设计

### 1.1 数据模型

multica 的 ScheduleConfig 由三个独立维度组成：

```typescript
interface ScheduleConfig {
  time: TimePattern;    // 时间模式
  days: DayPattern;     // 日期模式
  timezone: string;     // 时区
  raw: string | null;   // 高级模式原始表达式
}
```

**TimePattern**（两种）：
- `at`：固定时间 `{ kind: "at", time: "HH:MM" }`
- `every`：间隔模式 `{ kind: "every", interval, unit: "minutes"|"hours", window: {from, to} | null, minute }`

**DayPattern**（三种）：
- `every`：每天
- `weekly`：按周几 `{ daysOfWeek: number[] }`
- `monthly`：按日期 `{ dayOfMonth: number }`

### 1.2 关键设计原则

1. **三维度独立**：时间模式和日期模式是两个独立的 fieldset，用户分别选择，不混合
2. **窗口始终显示**：间隔模式的时间窗口始终可见（null = 全天），用户通过编辑窗口边界来收窄范围，不需要先"声明要窗口"
3. **窗口精度按 unit 变化**：
   - `unit=minutes` 时窗口是小时粒度（from :00, to :59）
   - `unit=hours` 时窗口带分钟（from 和 to 共享同一个 firing minute）
4. **全天 = window=null**：窗口跨 00:00-23:59 时自动转为 null（全天），只有一种表示
5. **模式切换保留值**：切换 at↔every 时用 anchor 记忆上一个值，切回来不丢失
6. **cron 表达式是派生视图**：结构化模型是唯一真实来源，cron 文本只是展示+编辑入口
7. **高级模式**：当表达式超出结构化模型范围，进入 raw 模式，控件灰色禁用，只显示原始 cron 输入框
8. **描述 + 预览**：描述是结构化模型的人类可读句子，预览（下次运行时间）由服务端计算

### 1.3 cron 映射规则

**结构化 → cron**：
```
at: M H * * *
every hours, no window: M */N * * *
every hours, window: M fromH-toH/N * * *
every minutes, no window: */N * * * *
every minutes, window: */N fromH-toH * * *
weekly: M H * * D1-D2,D3
monthly: M H DOM * *
```

**cron → 结构化**（parseCron）：
- 先归一化（去空、数字去前导零、`?`→`*`）
- 逐字段解析：minute → hour → dom/dow
- 退化步长折叠（`*/65` → `0`）
- 无法结构化 → 进入 raw 高级模式

## 2. Grape 当前实现的问题

| 问题 | 原因 |
|------|------|
| 时间窗口分钟被丢弃 | 只取 `parseInt(winS.split(':')[0])`，忽略分钟 |
| 预览不实时 | onchange 而非 oninput（已修复） |
| 每月日期选不了 | innerHTML += 重置 DOM（已修复，改为网格） |
| 高级模式描述重复 | _apDescribeCron 返回原始 cron（已修复） |
| UTC 时区偏移 | 后端用 UTC 计算（已修复，改为本地时区） |
| 时间模式和日期模式耦合 | 每天/每周/每月是三个互斥按钮，不是独立维度 |
| 窗口精度不明确 | time input 暗示分钟精度但 cron 只支持小时粒度（已修复，改为 select） |

## 3. 重构方案

### 3.1 三维度独立布局

```
┌──────────────────────────────────────────────┐
│ 时间                                          │
│ [固定时间] [间隔执行]                          │
│                                              │
│ 固定时间模式:                                 │
│   时间: [09]:[00]                             │
│                                              │
│ 间隔执行模式:                                 │
│   每 [30] [分钟▼]  时间窗口: [09]:[00] ~ [17]:[59] │
│                                              │
│ 日期                                          │
│ [每天▼]                                       │
│                                              │
│ 每天模式: (无额外控件)                         │
│ 每周模式: [日][一][二][三][四][五][六]         │
│ 每月模式: 日期 [1▼] (1-31网格)                │
│                                              │
│ 时区                                          │
│ [Asia/Shanghai▼]                              │
│                                              │
│ ┌─ 预览 ────────────────────────────────────┐ │
│ │ 🕒 每天 09:00                              │ │
│ │ 0 9 * * *                                  │ │
│ │ 下次运行:                                  │ │
│ │   09/21 09:00                              │ │
│ │   09/22 09:00                              │ │
│ │   09/23 09:00                              │ │
│ └───────────────────────────────────────────┘ │
│                                              │
│ [高级模式: 点击 cron 表达式编辑]               │
└──────────────────────────────────────────────┘
```

### 3.2 时间模式（TimePattern）

**固定时间（at）**：
- 一个 time input：HH:MM
- 生成 cron：`M H * * *`（日期部分由日期模式决定）

**间隔执行（every）**：
- 频率：`每 [N] [分钟/小时▼]`
- 时间窗口：`[from] ~ [to]`（始终显示，null = 全天）
- `unit=minutes` 时窗口只选小时（from :00, to :59）
- `unit=hours` 时窗口带分钟（from 和 to 共享 firing minute）
- 全天（00:00-23:59）自动转为 window=null

### 3.3 日期模式（DayPattern）

用下拉选择三种模式：
- **每天**：无额外控件
- **每周**：7 个 toggle 按钮（日/一/二/三/四/五/六），至少选一个
- **每月**：1-31 网格选择器（7列），≥29 时提示"短月可能不触发"

### 3.4 时区

- 下拉选择 IANA 时区
- 默认浏览器时区
- cron 按所选时区计算

### 3.5 预览面板

- 人类可读描述（如"每天 09:00 · 每周一、三、五 14:30"）
- cron 表达式（等宽字体）
- 下次运行时间（3个，服务端计算或前端计算）

### 3.6 高级模式

- 点击 cron 表达式行 → 切换为文本输入框
- 输入后 onblur 尝试 parseCron → 能结构化则恢复控件，不能则进入高级模式
- 高级模式下结构化控件灰色禁用
- 时区始终可编辑

### 3.7 cron 映射

**toCron（结构化 → cron）**：
```
固定时间 + 每天:     M H * * *
固定时间 + 每周:     M H * * D
固定时间 + 每月:     M H DOM * *
间隔分钟 + 全天:     */N * * * *
间隔分钟 + 窗口:     */N fromH-toH * * *
间隔小时 + 全天:     M */N * * *
间隔小时 + 窗口:     M fromH-toH/N * * *
```

**parseCron（cron → 结构化）**：
- 5 段制标准 cron
- 逐字段解析 minute → hour → dom/dow
- 识别 at / every(minutes) / every(hours) + window
- 识别 every / weekly / monthly
- 无法识别 → raw 高级模式

## 5. 与当前实现的主要差异

| 维度 | 当前 | 重构后 |
|------|------|--------|
| 布局 | 5 个互斥按钮（固定/间隔/每周/每月/高级） | 2 个独立维度（时间 + 日期）+ 时区 + 高级 |
| 时间窗口 | time input（分钟精度，被丢弃） | 按 unit 变化精度，始终显示 |
| 日期模式 | 和时间模式耦合（每周按钮同时设时间+日期） | 独立下拉（每天/每周/每月） |
| 高级模式 | 独立按钮 | 点击 cron 表达式切换 |
| 时区 | 无 | 下拉选择 |
| 全天 | 无窗口 = 不显示窗口控件 | 窗口始终显示，全天 = 00:00-23:59 |
| 模式切换 | 切换时重置 | 用 anchor 记忆，切回来恢复 |
