# Issue #3227 需求文档

## 背景
技能详情页「概览」Tab 现有层级为：摘要纯文本 → 元信息表 → 结构化概述 → 概述原文 → 用户评论，与需求的目标四层顺序不一致；摘要无卡片标题且缺少字数下限；结构化概述直接抓取 SKILL.md 章节原文并按 120 字硬截，未做结构化摘写。

## 目标
- 概览 Tab 自上而下四层：元信息表 → 卡片摘要 → 技能概述 → 技能介绍（用户评论保留末尾）。
- 摘要改为独立卡片，以摘要文本作为卡片标题，正文 15–50 字。
- 「概述原文」更名为「技能概述」。
- 「结构化概述」更名为「技能介绍」，移除「总体说明」，段序为：适用范围 → 关键步骤链 → 产物说明 → 约束简述。
- 技能介绍由 SKILL.md 句界摘写，禁止原文 120 字盲截，缺段不渲染、不虚构。

## 范围
### In Scope
- `src/api/frontend/app/src/views/SkillsView.vue`：概览模板重排、摘要标题/正文取值、`extractOverview` 摘写与段序、`KEY_DEFAULTS` 文案、摘要卡片样式。

### Out of Scope
- 不改后端 API / 数据库，不引入 LLM。
- 不改其他 Tab 与评论提交链路。
- 不改写历史评论或 Issue 描述。

## 验收标准
- [ ] 概览四层顺序正确，用户评论在末尾。
- [ ] 摘要卡片标题取摘要文本，正文 15–50 字，超长按句界截断、不足按规则回退，与标题相同或无法补足时不渲染正文。
- [ ] 页面无「概述原文」「结构化概述」「总体说明」及旧 key 残留。
- [ ] 技能介绍段序为：适用范围 → 关键步骤链 → 产物说明 → 约束简述；前两段各一句，后两段各 30–50 字。
- [ ] 摘写按句界切分，无 120 字硬截；缺失段不渲染。
- [ ] `npm run lint` 与 `npm run build` 通过。
