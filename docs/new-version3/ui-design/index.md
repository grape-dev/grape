## 7. Event Detail 页

> 实现：`events.js renderEventDetail` + 对话流（SSE）+ 实时日志

```
┌─ Event Detail · VOD Agent · team/backend-service ───────────┐
│  [← VOD Agent]                                               │
│  ┌─ 左栏 ──────────────────────┐  ┌─ 右栏 ───────────────┐ │
│  │  [‹]  Event #1234  [›]     │  │  💬 与 VOD Agent 对话  │ │
│  │  ─ Context & Info (折叠▼) ─ │  │  [⛶]                 │ │
│  │  Trigger: issue_opened      │  │  ┌─────────────┐     │ │
│  │  Repository: own/name       │  │  │ user: 为什么？│     │ │
│  │  Issue: #345 ↗              │  │  │ agent: 因为… │     │ │
│  │  Actor: @alice · Time:…     │  │  └─────────────┘     │ │
│  │  Seq #1234 │ Engine: opencode│ │  [输入消息…] [发送]    │ │
│  │  (·device ·ip) │ Skill: vod│ │  （gate 开/关徽章）      │ │
│  │  Duration: 12s │ Status: ✅ │ │  ⛶ 全屏                 │ │
│  │  [🔄重派] [⏹终止(运行中)]    │  └──────────────────────┘ │
│  │  [查看实时日志]              │                           │
│  │  ─ 接收上下文 (折叠▶) ─     │  对话产出:                │ │
│  │  （黑底 mono prompt 全文）   │  知识沉淀 / 流程操作       │ │
│  │  ─ Agent 处理记录与答复结论 ─│                           │ │
│  │  结构化产出: 结论/动作/产出/ │                           │ │
│  │   下一步/Issue 摘要         │                           │ │
│  │  <Markdown 答复结论渲染>    │                           │ │
│  └─────────────────────────────┘  └────────────────────────┘ │
└──────────────────────────────────────────────────────────────┘
```

要点：
- 左栏上下导航 `‹ ›` 切换相邻事件；参考事件不存在时自动跳 max_seq。
- Context & Info 可折叠：Context（Trigger/Repository/Issue/Actor/Time）+ Info（Seq/Engine+device+IP/Skill/Duration/Status）。
- Status 区动态按钮：失败或运行超时>10min 显示 `🔄 重派`（毛玻璃确认弹窗）；运行中显示 `⏹ 终止`。
- 日志：有 task_id → Task Logs SSE 实时面板（可复制/杀任务/全屏，含引擎/设备/IP 抬头）；无 task_id（direct）→ 内联 `agent_logs` 面板。
- 接收上下文（prompt）：异步从 task-logs info 拉取，黑底等宽、字符计数、支持全屏；ESC 退出。
- 右栏对话：submit/stream 分离——先得 task_id，再 SSE 流式渲染（3 点动画→流式+底部 ticker），切换页面自动中断 SSE、切回自动 `resumeConvTask` 重连；会话 gate 决定输入框显隐。
