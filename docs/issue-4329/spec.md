# Spec: 评论发布前一致性断言把样例前缀/测试文件名误判为 Issue 主语（Issue #4329）

## 目标
- 收紧 `src/domains/runtime/vcs/release_guard.py` 的 `_ANCHOR_RE`：显式主语 + 词元/路径边界。
- 样例前缀（`issue456_*`）、测试文件名/路径（`test_issue190_*.py`）不再被当成正文主语而 409。
- 正文显式引用其它 Issue（`Issue #N` / `Issue N`）仍拦截；裸 `#N` 不提升为正文主语。

## 边界设计
- 前置断言 `(?<![A-Za-z0-9_/.])`：显式 ASCII 字符集（不含中文），保留「实现Issue #2225」中文紧邻合法主语；排除标识符/路径前缀。
- `Issue` 与编号之间至少一个空白，`#` 可选：`issues?\s+(?:#\s*)?(\d+)`。
- 编号后负向前瞻 `(?![A-Za-z0-9_])`：排除 `Issue 456_*`、`Issue 456abc` 续写形态。
- 移植同域 4257 单的 `_CHAIN_REF_RE`（`\w+#\d+`）+ `_strip_chain_refs` 链路引用剔除（`weekly-mys` 基线已含，本单锚点收紧叠加其上）。

## 验收
1. 样例前缀放行（`issue456_*` 等）。
2. `test_issue<数字>_*.py` 类文件名/路径放行。
3. 正文显式引用其它 Issue 仍 409。
4. 既有语义与链路引用不回归（2225/3811/4257 三套守卫用例全通过）。
