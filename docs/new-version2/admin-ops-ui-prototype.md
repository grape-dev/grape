# Grape 管理运营系统 — 界面原型视图（Wireframes）

> 版本：v1.0
> 日期：2026-08-08
> 配套：`admin-ops-design.md`（功能模块）/ `admin-ops-prototype.html`（高保真）
> 说明：本文为**低精度线框**，标注每个管理页面的布局、区块与交互；高保真样式见同名 HTML 原型（可直接浏览器打开）。

## 一、导航结构

