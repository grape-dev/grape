# Simple Text Analyzer

## 场景
用户需要对文本进行统计分析时使用本技能。
交互逻辑（与模板下载同一模式）：
① 点击「下载技能」→ 前端调 GET /api/skills/{name}/download（点击时动态签发）
② 接口返回 {"url": "https://obs.../xxx.zip?签名参数", "expires_in": 300}（OBS 临时签名 URL，300s 有效）
③ 前端 window.open(url) → 浏览器直连 OBS 下载 zip，不经过服务端
④ OBS 未启用（local 模式）→ 接口返回文件流，前端回退原路径下载（与模板下载适配一致）

实现改动点（3 处）

  1. 后端接口：skills.py 新增 GET /api/skills/{name}/download —— OBS 分支：查 DB 记录 → 拿对象键 → 签发临时 URL → {url, expires_in}； local 分支：本地技能目录打包 FileResponse 流式返回
  2. 前端按钮：renderSkillDetail 头部行（display:flex 加 justify-content:space-between） → 右侧加「⬇ 下载技能」按钮（.bt 样式，onclick 调 downloadSkillZip）
  3. 前端下载函数：skills.js 新增 downloadSkillZip(name, scope, repo) —— fetch 接口拿 {url} → window.open(url)；local 模式回退原路径
