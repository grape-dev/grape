# Spec: Issue #1748 — 纯视频/图片附件评论无法被 Agent 解析

## 需求
`issue_comment` 事件中，用户仅上传视频/图片附件（`https://gitcode.com/user-attachments/...`）时：
1. 事件注入缺少媒体分析段落，Agent 拿不到画面内容；
2. 附件直链需登录态，Agent 无凭证访问返回 401。
双重断链导致 Agent 只能回退要求用户补充文字描述。

## 目标
- 评论事件构建期识别媒体附件 → 服务端带凭证下载 → 产出媒体分析段落注入 Agent 上下文。
- 为 Agent 提供无凭证、无 401 的附件读取通道（复用平台附件存储/签名 URL）。
- 附件不可读时注入明确原因（HTTP 401 / 超时 / 格式不支持 / 无 token 等），不静默缺失。
- 纯文本评论注入行为保持不变（回归）。

## 范围
- In：`src/vcs/api_client.py` 附件链接识别与鉴权下载；`src/api/issues_center.py` 附件采集编排；`src/prompt_builder.py` 评论媒体分析注入；`tests/` 回归。
- Out：VCS 页面附件展示与权限模型；公网长期免登录直链；重做现有图片/视频分析能力（仅复用）。

## 验收
- [ ] 仅含视频附件的评论触发 `issue_comment` 后，Agent 上下文出现「用户上传的视频分析」段落（含摘要或明确的不可读原因）。
- [ ] 注入的读取通道 URL 为服务端凭证下载后转存的平台附件 URL，Agent 访问不再 401。
- [ ] 图片附件复用现有图片分析能力，输出「用户上传的图片分析」。
- [ ] 附件解析失败注入具体原因，不静默缺失。
- [ ] 纯文本评论不新增媒体段落；现有测试通过。
- [ ] token 不出现在 prompt / 日志 / 评论中。

## 风险
- 视频转写/关键帧分析成本：沿用 `understand_video` 的 50MB / 120s / 6 帧阈值，超限降级为明确原因。
- 预签名 URL 时效：复用 `_attach_save`（OBS 7 天签名 / 本地静态 URL），仅注入短时效读取通道。
- 事件注入膨胀：分析摘要本身限长，附件按数量上限采集。
