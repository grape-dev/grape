# Spec: Issue #402 — 项目场景详情页「复制场景」按钮

> 来源：Issue #402 Spec Document（）| 目标分支: 功能分支

## 目标
项目场景详情页（scene-detail-local）新增「复制场景」按钮，一键复制现有场景完整配置为可编辑副本，默认命名 `<源场景名>-copy`，减少重复配置成本。

## 范围
### In
- 后端 `POST /api/scenes/{scene_id}/copy`（复用 `_query_scene_by_id` 读取 + `create_custom_scene` 创建）
- 前端 dashboard.js 详情页新增复制按钮 + 确认弹窗（名称预填可编辑），成功后跳转新场景详情
- 复制内容：nodes（节点/技能绑定/流转）、名称/描述/图标、PR 订阅开关、关联仓库；名称冲突自动追加序号（-copy2…），超 40 字符截断
- SRE 个人机器引擎不跨用户复制（剔除回退广播）；无效引擎 ID 优雅剔除
- official 场景可复制为 repo 级副本
- i18n 文案（中英）+ docs/openapi/06-scenes.md、help/api/06-scenes.md 文档 + 后端/前端测试

### Out
- 场景市场详情页（scene-detail）复制入口
- 跨仓库复制
- 高级选项（工作分支/自定义 KV）迁移（与 scene_id 绑定，副本重新配置）

## 验收标准
- 详情页可见复制按钮，弹窗名称默认 `<源场景名>-copy` 可编辑
- 副本配置与源一致，修改副本不影响源
- 名称冲突自动追加序号、超 40 字符截断
- SRE 个人机器引擎不跨用户复制、无效 ID 优雅剔除
- 现有测试全过 + 新增测试覆盖复制端点与前端交互
