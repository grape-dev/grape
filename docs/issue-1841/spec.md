# Issue #1841 — 场景注入工作基线分支（GRAPE_WORK_BRANCH）存在性校验与安全回退

> 需求 Spec 由 Issue Agent 输出（Issue #1841 评论 199631023），本文件为实现侧对齐摘要，不重复生成需求。

## 目标

场景配置的 `work_branch` 在注入 `GRAPE_WORK_BRANCH` 前先做存在性校验；失效配置回退目标仓库默认分支并告警（记录原配置值、仓库、生效分支）。

## 范围

1. 注入前校验：`work_branch` 不在目标仓库分支列表 → 回退默认分支 + WARNING 告警。
2. 场景/流水线配置保存校验：失效分支返回明确 400 校验错误，前端 toast 提示。
3. Prompt 注入处标注实际生效分支与回退原因。
4. 运维脚本扫描存量 `devops_pipeline_scene.advanced_options.work_branch`，输出失效清单并支持批量校正。

## 非目标

- 不修改 GitCode「ref 不存在静默回退默认分支」的平台行为。
- 不自动创建/改名分支。

## 验收标准

- [ ] 配置不存在的 work_branch 触发流水线：注入值为仓库默认分支，且有含原配置值的告警记录。
- [ ] 保存场景配置时，前端对不存在的 work_branch 给出提示。
- [ ] Agent prompt 中可见实际生效分支与回退原因。
- [ ] 存量过期 work_branch 可被运维脚本识别并批量校正。
- [ ] 现有测试通过；新增校验/回退/标注路径测试。
