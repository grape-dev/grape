# Issue #4172 需求文档（Spec）

## 1. 背景

「项目」页（`src/api/frontend/app/src/views/ReposView.vue`）存在三处交互问题：

1. 「新建项目」按钮位于右侧操作区首位，顺序为「新建项目 → 范围切换 → 刷新 → 搜索框」，
   常用操作被排在搜索框之前。
2. 范围切换按钮文案描述的是**当前状态**而非点击后的目标视图：默认 `onlyHosted=true`
   时显示「只看已托管」，用户按文案理解为「点击查看全部仓库」，实际点击后仍是已托管列表。
   对应 tooltip 同样是当前态描述。
3. 无托管仓库空态中的「全部仓库」是纯文本，无法直接从空态切到全部仓库视图。

## 2. 目标

优化项目页交互：按钮位置、范围切换文案语义、空态一键切换。

## 3. 范围

### In Scope

1. 右侧操作区顺序改为：范围切换 → 刷新 → 搜索框 → 新建项目；
   新建项目按钮样式与打开新建仓库弹窗行为不变。
2. 范围切换按钮文案 = 点击后将要切换到的目标视图（与当前相反）：
   - `onlyHosted=true`（默认）→ 显示「全部仓库」，点击后展示全部仓库并变为「只看已托管」；
   - `onlyHosted=false` → 显示「只看已托管」，点击后仅展示已托管并变为「全部仓库」。
   - 首屏默认视图仍为「只看已托管」；tooltip 改为描述点击效果，zh/en locale 同步。
3. 无托管仓库空态：「全部仓库」为可点击元素，点击立即切到全部仓库视图；
   全部仓库为 0 条时仍显示通用空态。

### Out of Scope

- 不改动列表排序、搜索、平台筛选、分页逻辑。
- 不改动托管/建仓接口与弹窗流程。
- 不改动工作台（workspace）与模板（templates）页。

## 4. 验收标准

- [ ] 右侧操作区顺序为范围切换、刷新、搜索框、新建项目；新建项目在搜索框右侧且仍能打开新建弹窗。
- [ ] 首屏已托管列表、按钮「全部仓库」；点击后全部仓库列表、文案「只看已托管」；再点回已托管、文案「全部仓库」；即时生效。
- [ ] 切换后列表内容与按钮文案严格对应，无错位。
- [ ] 无托管仓库时空态正文「全部仓库」可点击并切到全部仓库视图。
- [ ] 全部仓库为 0 条时仍显示通用空态。
- [ ] zh/en 双语 locale 同步（按钮文案、tooltip、空态）。
- [ ] 补充 `tests/js/` 回归用例覆盖按钮顺序、切换文案与列表一致性、空态跳转，相关套件通过。
