### 5.3 踩过并回退的坑（不要再走一遍）
1. **`im/engine_wiring._connect()` 是跨域共用句柄**：`grape_t_channel_installation` 归 mgmt、
   `agent_runtimes` 归 runtime。把整条连接改指任一域，必打断另一侧（实测打出 `/api/im/*` 与
   `/api/chat/config` 的 1146）。正解：**按表把 SQL 拆到各自 owner 模块**（`3921a54c6` 已做安装表那一半）。
2. **session_manager chat 两表那批曾两次回退**：改完 chat 配置解析后 `PUT /api/chat/config` 报
   `1146 ... agent_runtimes`。修法已成型：`_chat_config_row_engine` 用 `runtime_public.runtime_name()`
   原语（而不是在 kernel 里查 agent_runtimes），其余会话/消息 SQL 走 runtime public 具名查询。
   **重放这批时先做这一个函数、跑一次冒烟，再铺开。**
3. **`owner_lib` 只解决「有 DSN 时」**：老代码为单库拓扑保留了本地兜底 SQL，而兜底 SQL 正是跨域统计的来源。
   正解是「任意拓扑」原语（自有 DSN 走 db_registry，单库回落进程库），SQL 只留 owner 域一份。
4. **后台线程不能共用 owner 连接**：把 `credential_usage_log` 的 flush/retention 直接改成 `domain_db.cursor("runtime")`
   会打出 `Packet sequence number wrong`；需要「每工作线程一条连接」的池化，属独立一轮工作，**别顺手改**。
5. **静态正则不计 `CREATE TABLE IF NOT EXISTS`**：DDL 归位不会让数字下降（但结构上仍然该做，已做）。

## 8. 其余已知坑（都是本会话实测）

- 测试只跑 `tests/arch tests/contracts tests/scripts` 这三组（稳定）；`tests/api`、`tests/kernel`、`tests/insight` 有大量**既有失败**，别当成自己弄红的，要用 `git stash` 前后对比（工作区有别人的并行改动时不要 stash）。
- 静默 except 棘轮：`tests/arch/test_silent_except_ratchet.py` 里 `EXEMPT_FILES` 按「路径 + 行内容」登记；搬文件要同步改路径，新增 `except: pass` 会红——改成带 `log.warning` 的显式处理。
- `tests/silent_except_baseline.json` 同理按路径记数，搬文件要改键。
- `check_lib_query_names`：跨域调用的每个函数/具名查询都必须登记在 owner public 的注册面（`def` 或 `_ANY_QUERIES` 键）；常量属性不算。
- `pymysql` 执行含 `%` 的 SQL 时**不能**传空参数元组（会被当格式符）→ `c.execute(sql)` 与 `c.execute(sql, args)` 要分开写。
- **`db_registry` 的薄兼容游标不翻译 PRAGMA**（只有 `mysql_compat.Cursor` 有 PRAGMA 特判）：
  在 `_any_cursor()` / `db_registry.cursor()` 上直发 `PRAGMA table_info(x)` 在 MySQL 上必 1064。
  需要探测列时用 `SELECT * FROM x LIMIT 0` 读 `c.description`（两条后端一致），
  或走 `information_schema.columns`；`mysql_compat` 那条 PRAGMA 翻译只对进程主库 `db` 生效。
- MySQL 8 dump 导进 MariaDB 10.11 会因生成列 DDL 报 1064 → 彩排统一 MySQL 8。
- 远端实例启动若报 `Failed to access directory for --secure-file-priv`，先 `mkdir files` 再启。
- `data/test_sessions.db` 本地污染会让 A2A 用例假红 → 删掉重跑。
- 全量 `make test-domains` 不可靠（日志会被测试自身清理、进程空转），用分域 pytest。
- 提交前扫敏感信息：`git diff --cached | grep -cE "192\.168\.|/home/grape|Grapedev@|Grape@123"` 必须为 0。
