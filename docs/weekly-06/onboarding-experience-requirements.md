## 1. 背景与目标

### 1.1 现状分析

用户通过邮箱注册或 OAuth 首次登录后，如果没有绑定任何代码托管平台，系统展示新手引导页。该页面此前经历了多轮迭代，最终形成了包含工作流演示、Agent 架构展示、基础设施特性卡片、底部 CTA 和引流入口的"渐进式产品概览"页面。

实际使用中发现，这些产品介绍内容没有达到预期效果：

- **用户目标是绑定平台开始使用，不是阅读产品说明书**。注册后的核心诉求是"绑哪个平台、怎么绑"，而非浏览 Agent 架构或工作流演示
- **页面过长，绑定入口被淹没**。多屏滚动内容分散注意力，用户反而不容易找到绑定按钮
- **内容维护成本高**。引导页的产品介绍内容需要和官网保持同步，两处维护容易不一致
- **用户了解产品应该去官网**。引导页和官网职责不同：官网做产品展示，引导页做行动引导

### 1.2 目标

将引导页简化为单屏绑定页面，只做一件事：让用户绑定代码托管平台。

1. **只保留绑定能力**：欢迎语 + 平台绑定卡片，一屏到位，不滚动
2. **删除全部产品介绍内容**：工作流演示、Agent 架构、基础设施特性、底部 CTA、引流入口全部移除
3. **删除滚动动画体系**：连续阻尼滚动引擎、进度条、浮动按钮、IO 揭示动画全部移除

### 1.3 设计原则

- **行动优先且唯一**：引导页只做绑定引导，不做产品介绍。用户想了解产品去官网
- **一屏到位**：所有内容在一屏内可见，不需要滚动
- **复用现有框架**：继续使用 lobby 壳框架和顶栏（Logo + 组织下拉 + 用户菜单），不自建独立页面壳
- **职责分离**：引导页 = 行动引导，官网 = 产品展示，用户设置 = 绑定管理

## 2. 用户角色与场景

### 2.1 用户角色

| 角色 | 特征 | 核心诉求 |
|------|------|----------|
| 新注册用户 | 刚完成邮箱注册，未绑定平台 | 快速绑定平台开始使用 |
| OAuth 首次登录用户 | 通过第三方平台 OAuth 登录，已自动创建账号 | 系统已检测到绑定，不会看到引导页 |

### 2.2 用户旅程

```
邮箱注册/登录成功
  → 系统检测绑定状态
  → 未绑定任何平台
  → 展示单屏引导页
    → 欢迎语 + 平台绑定卡片
    → 用户点击绑定
    → OAuth 授权完成
    → 自动进入项目页
```

## 3. 需求清单

### 需求 31：新手引导页 — 单屏绑定

**用户故事：** 作为一名刚注册登录的新用户，我希望在尚未绑定平台时看到一个简洁的引导页，第一眼就能找到绑定入口开始使用，不需要浏览产品介绍或滚动查找，以便最快速度完成绑定进入工作状态。

**业务流程：**

1. 用户完成登录，系统检测到用户尚未绑定任何代码托管平台
2. 系统展示引导页，页面仅包含以下内容：
   - **品牌头部栏**：Logo + 组织下拉 + 用户菜单（与已绑定后的 lobby 页面头部一致）
   - **欢迎区域**（垂直居中，一屏可见）：个性化欢迎语 + 产品定位语 + 平台绑定卡片
3. 用户在欢迎区域点击绑定按钮进入绑定流程
4. 绑定成功后，系统自动进入项目页

**页面结构：**

```
顶栏（Logo + 组织下拉 + 用户菜单）
  └─ 单屏居中布局
       ├─ 欢迎语（用户名 + "欢迎使用 Grape"）
       ├─ 产品定位语（一句话）
       ├─ 平台绑定卡片（横向排列，每张：平台图标 + 名称 + "绑定"按钮）
       └─ 底部小提示（"绑定后自动进入工作台 · 可在用户设置管理绑定"）
```

**业务规则：**

- 引导页仅在用户未绑定任何代码托管平台时展示
- 已绑定平台的用户直接进入工作台，不展示引导页
- 引导页保留顶部品牌头部栏（Logo + 组织下拉 + 用户菜单），与 lobby 页面头部一致
- 引导页不展示项目列表、模板、工作空间的 Tab 切换条
- 引导页不展示产品介绍内容（工作流演示、Agent 架构、基础设施特性、底部 CTA、引流入口）
- 引导页不展示进度条、浮动按钮、滚动动画
- 欢迎区域使用个性化欢迎语（显示用户名），配品牌 Logo 和一句话产品定位语
- 欢迎区域底部放置平台绑定卡片，所有绑定入口在一屏内可见，不需要滚动
- 平台绑定卡片根据系统已配置的平台动态展示，未配置的平台不展示
- 每张绑定卡片包含：平台图标 + 平台名称 + "绑定"按钮
- 绑定按钮点击后进入平台 OAuth 绑定流程，行为与用户设置中的绑定操作一致
- 绑定成功后系统自动进入项目页，不停留在引导页
- 页面底部可显示一行小提示文字，告知用户绑定后自动进入工作台、可在用户设置管理绑定
- 用户头像下拉菜单提供"用户设置"和"登出"入口

**验收标准：**

1. 未绑定平台的用户登录后看到引导页
2. 引导页顶部有品牌头部栏（Logo + 组织下拉 + 用户菜单），与 lobby 页面头部一致
3. 引导页所有内容在一屏内可见，不需要滚动
4. 引导页包含个性化欢迎语、产品定位语和平台绑定卡片
5. 引导页不展示项目/模板/工作空间 Tab 切换条
6. 引导页不展示工作流演示、Agent 架构、基础设施特性、底部 CTA、引流入口
7. 引导页不展示进度条、浮动按钮、滚动动画
8. 已绑定平台的用户不看到引导页，直接进入工作台
9. 绑定成功后自动进入工作台，不停留在引导页
10. 引导页列出所有已配置的平台，未配置的平台不展示
11. 引导页支持中英文切换

## 4. 国际化要求

所有展示内容均需支持中英文双语。

| 内容区域 | 中文示例 | 英文示例 |
|----------|----------|----------|
| 欢迎语 | 欢迎使用 Grape | Welcome to Grape |
| 产品定位语 | 自主 Agent · 事件驱动 DevOps | Autonomous agents · Event-driven DevOps |
| 绑定按钮 | 绑定 | Connect |
| 底部提示 | 绑定后自动进入工作台 · 可在用户设置管理绑定 | Auto-enters workspace after binding · Manage in Settings |
