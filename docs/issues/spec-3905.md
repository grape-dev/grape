# Spec: Issue #3905 — 运行时 env 契约三变量恒缺失（issue / autopilot 派发路径）

> 来源：Issue #3905 + Issue Agent Spec 评论 | 工作基线：`arch-weekly-11-ljt` | 缺陷修复（非架构变更）

## 目标
让 issue 任务（含 autopilot 直连派发、`backend=hermes` 的 ACP 子进程）稳定拿到
`ACCOUNT` / `GRAPE_ISSUE_ID` / `GRAPE_WORK_BRANCH`，消除「全程 degraded env」与
`ACCOUNT_MISSING`。

## 现状（本基线逐行复核）
生产 Loki（job=grape-prod）：`runtime env contract missing` 1h 46 / 24h 949；
`ACCOUNT_MISSING` 1h 45 / 24h 2,762。本基线四个断点仍在：

| # | 位置 | 现状 | 后果 |
|---|------|------|------|
| 1 | `event_pipeline._create_direct_task` | env 快照写死空对象（仅落 enc:v1 信封的空 `{}`） | direct/failed 快照是重派、接管、超时收口、worker 侧 `decrypt_env_extra(task.env_extra)` 的唯一 env 来源 → 消费端三变量全缺 |
| 2 | `event_pipeline._create_failed_task` | 快照 env 仅 `REPO_KEY/REPO_FULL_NAME/REPO_OWNER/REPO_NAME/ACCOUNT` | 无 `ISSUE_NUMBER`（契约两条回退的唯一前置）/`PR_NUMBER`/`GRAPE_ISSUE_ID`/`GRAPE_WORK_BRANCH` |
| 3 | `event_pipeline._resolve_account_chain` + `scheduler` | `owner_fallback=False` 硬编码 | autopilot 无 actor，三级回退（actor → payload.account → issue_creator）恒空 → 每任务一条 `ACCOUNT_MISSING` |
| 4 | `executor._ACP_CONTEXT_ENV_KEYS` | 白名单独缺 `GRAPE_ISSUE_ID` | `backend=hermes` 子进程即使契约解析成功也读不到内部卡片 id |

`_apply_runtime_env_contract` 本身无缺陷（VOD 任务三变量齐全是反证）：`GRAPE_ISSUE_ID`、
`GRAPE_WORK_BRANCH` 两条回退都按 `env["ISSUE_NUMBER"]` 索引，源侧不补即恒空。

## 方案（填源 + 白名单 + 可观测，不改契约函数语义）
1. **填源（快照）**：`_create_direct_task` / `_create_failed_task` 改用 `build_task_env`
   （重派/对话入队同源实现）组装快照，再补 `evt._env_extra`、`REPO_KEY` 与
   `_inject_issue_pr_env`（`ISSUE_NUMBER` / `PR_NUMBER` / `GRAPE_ISSUE_ID`）。
   快照字段只增不减；组装失败降级空快照并告警，不阻断派发。
2. **账户兜底**：`_resolve_account_chain` 新增 `allow_owner_fallback`（默认 False）；
   `resolve_actor_account` 在事件类型为 `autopilot_event` 时自动放行；
   `account_env.owner_account_for_repo` 为属主派生单一实现；
   autopilot 命中输出 `ACCOUNT_OWNER_FALLBACK`（info，含 `account_source=repo_owner`）留审计，
   仍不可得才 `ACCOUNT_MISSING`（`owner_fallback=true`）。人工/a2a 事件路径**仍禁止**回退
   属主（Issue #1819 安全语义不变）。`scheduler._execute_autopilot_direct` 复用
   `_execute_autopilot_agent` 构造的 typed evt（`type=autopilot_event`）并附
   `_env_extra`（本次执行真实 env）后传给 `_create_direct_task`，让 `_dispatch_ident`
   走同一判定、快照与现场 env 一致。
3. **ACP 白名单**：`_ACP_CONTEXT_ENV_KEYS` 补 `GRAPE_ISSUE_ID`。
4. **可观测**：契约缺失按 `(backend, agent_type, var)` 计数
   （`grape_runtime_env_contract_missing_total`，低基数标签，repo/issue 号不进标签）；
   进程内连续 N（默认 10，`GRAPE_ENV_CONTRACT_STREAK_ALERT`）次三变量全缺升级 ERROR；
   `deploy/alerts.yml` 增 `GrapeRuntimeEnvContractMissing`（30m 增 10 次即告警）。

不回填存量任务快照（按 24h 指标收敛验收）。

## 验收
- [x] `_create_direct_task` / `_create_failed_task` 快照非空且含 `ISSUE_NUMBER`/`ACCOUNT`/`REPO_*`
- [x] mock **不含 `ISSUE_NUMBER`** 的 issue 任务（事件只有 `issue_id`）→ 四变量最终齐备
- [x] 无 actor 的 `autopilot_event` → `ACCOUNT` 经属主兜底非空且留 `ACCOUNT_OWNER_FALLBACK`；a2a 路径不回退（#1819 回归）
- [x] `backend=hermes` ACP 子进程 env 可见 `GRAPE_ISSUE_ID`
- [x] 缺失指标按 backend/agent_type/var 可查，连续全缺升级 ERROR，告警规则消费同一指标名
- [ ] 生产 Loki 两条查询 24h 归零（部署后验证，存量需逐条可解释）

## 复审修复（PR #2170 QA 审查）
| 级别 | 位置 | 问题 | 修复 |
|------|------|------|------|
| Required R1 | `scheduler._execute_autopilot_direct` | 传给 `_create_direct_task` 的是字面 evt（无 `type`）→ `_dispatch_ident` → `resolve_actor_account` 的 owner 回退判定失效，autopilot direct 快照 `ACCOUNT` 仍空 | 复用 `_execute_autopilot_agent` 的 typed evt（`type=autopilot_event`）并附 `_env_extra`（非空项才覆盖，避免清掉 `build_task_env` 已解析值）；源码守卫改到真实调用点 + 新增行为用例（修前失败/修后通过） |
| Optional | `event_pipeline._create_failed_task` | `build_task_env` 装配无异常兜底 → 失败快照整行丢失，重派命中「无关联任务」 | 装配失败降级到最小可解析子集（`REPO_*` + `ACCOUNT` + `ISSUE_NUMBER`/`PR_NUMBER`/`GRAPE_ISSUE_ID`）再落库，二次失败只丢扩展项 |
| Optional | `executor._record_contract_missing` | `_contract_streak` 进程级单计数：任一条 autopilot/chat 任务（`full_missing=false`）即清零，且跨 backend/agent_type 混合累计 → 混合流量下告警可能永不触发 | 计数改为按 `(backend, agent_type)` 分桶，且仅 Issue 域任务参与（autopilot/chat 直接跳过）；指标计数不受影响 |
| Nit | `tests/runtime/test_issue_3905_env_contract_completion.py` | 文件缺行尾换行；`..._carries_issue_and_pr_env` 名含 PR 但未断言 `PR_NUMBER` | 补行尾换行；事件带 `payload.pr_number` 并断言 `PR_NUMBER == "2170"` |

回归用例 17 → 21 条（新增：direct 侧 typed evt 行为契约、失败快照装配兜底、autopilot 不清零 issue 连续计数、连续计数按 backend/agent_type 分桶）。

## 风险与缓解
| 风险 | 缓解 |
|------|------|
| 快照变更波及其它 direct 类任务 | 字段只增不减；重派 `build_task_env` 不动，用 #1819/#3770/#3963/#372 现有用例回归 |
| 属主回退造成误归属 | 仅 autopilot / `autopilot_event` 生效；`ACCOUNT_OWNER_FALLBACK` + `account_source` 入日志审计 |
| 指标标签高基数 | 只放 backend/agent_type/var 三个低基数字典值，repo/issue 号不进标签 |
