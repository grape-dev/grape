# Help 页面原型图（v2 改版 · 双区分离）

> 版本：v2（评审修订）
> 日期：2026-09-11
> 参考：https://docs.gitcode.com/ 文档设计（帮助中心双入口 + 左目录常驻 + 右内容区切换）
> 说明：`/static/help.html` 仍为页面壳；内容由 `help/usage` + `help/api` 提供（唯一事实源不变）。
> 变更点（对 v1 的修订）：
> 1. 打开帮助页**先进入入口页**，给出「使用文档 / API 文档」两个选项，不再直接进使用说明主页；
> 2. API 文档与使用文档**分页展示**；
> 3. 目录**按区块独立**：使用文档页左侧只含使用指南目录，API 页左侧只含 API 目录；
> 4. 点击目录子项**左侧目录栏常驻不动**，仅右侧展示区切换渲染对应 markdown。

## 0. 信息架构（总览）

```
/static/help.html （壳）
        │  打开
        ▼
┌─ 入口页（帮助中心）───────────────────────────┐
│  [使用文档]   [API 文档]    ← 二选一进入        │
└──────────────────────────────────────────────┘
        │ 进入使用文档                  │ 进入 API 文档
        ▼                               ▼
┌─ 使用文档页 ─────────────┐   ┌─ API 文档页 ──────────────┐
│ 左目录: 使用指南 9 章      │   │ 左目录: API 13 文件       │
│ 右区  : 当前章节 md 渲染   │   │ 顶部  : ⬇ 下载 openapi.json│
│ 点击子项仅右区切换         │   │ 右区  : 当前接口 md 渲染   │
└───────────────────────────┘   └──────────────────────────┘
```
数据源：help/usage(9) + help/api(13 md) + help/api/openapi.json(契约)

### 2.2 左侧目录（仅使用指南）—— 同级对齐

```
┌─ 左目录 ─────────────────────────┐
│  使用指南                          │
│  ├─ 1. 平台概览                    │
│  ├─ 2. 快速上手 ◉ 当前章节高亮     │
│  │    ├─ 2.1 登录与仓库选择        │
│  │    ├─ 2.2 创建第一个 Issue      │   ← 与 2.1 同级同缩进
│  │    ├─ 2.3 查看任务进度          │
│  │    └─ 2.4 评审与合并 PR         │
│  ├─ 3. DevOps Agent 详解           │
│  │    └─（VOD / Issue / Coding /   │   ← 3.x 同级（独立章节，非嵌套）
│  │       QA / SRE 子项）           │
│  ├─ …（9 章）                      │
│  └─ 9. 常见问题 (FAQ)              │
└─────────────────────────────────┘
```

要点：
- **同级即同缩进**：2.1 / 2.2 / 2.3 / 2.4 平级展示（同一缩进 + 树形连接线），**不互为父子**。
- 缩进只表示"一级"与"子级"两种深度：章节（H1）=第 1 列；小节（H2/H3）=统一子列，同级统一对齐。
- 目录只含 `help/usage/` 的 9 个文档；**不含 API 条目**。
- 当前章节高亮态（◉ / 底色），可选折叠与滚动跟随（scrollspy）。

### 2.3 右侧内容区

- 默认显示「1. 平台概览」或上一记忆章节；点击左目录任一项 → **仅右区替换渲染**为对应 `usage/*.md`。
- **框线收敛规则**（针对"大量带框线"的调整）：
  - 每次只渲染**一个文档**（不再 9+13 章整页拼接）；
  - 章节 H1 保留细下划线；**H2/H3 不用独立边框卡片**（只做轻量标题样式，正文段落无框）；
  - 仅 `💡/⚠️` 提示引用与 `pre` 代码块保留边框 → 右侧无大量重复框线。
- 渲染能力：H1/H2/H3、列表、表格、代码块、提示卡片、FAQ（可加折叠）。

### 3.1 OpenAPI 契约下载（API 文档上方）

```
┌─ API 文档区顶部 ──────────────────────────────────────────┐
│  OpenAPI 契约                         [⬇ 下载 openapi.json] │
│  OpenAPI 3.1.0 · 42 路径 · 认证: Bearer / PRIVATE-TOKEN /   │
│  access_token 三通道                                        │
└─────────────────────────────────────────────────────────────┘
```

要点：
- **文件位置**：`help/api/openapi.json`（随 help 目录一起作为契约数据源）。
- **格式**：与 `https://gitcode.com/grape-dev/grape-cli/blob/main/src/data/openapi.json` 一致 —— 即 `src/api/openapi.py::custom_openapi(app)` 产出的对外安全契约（OpenAPI 3.1.0；只含对外安全路由；securitySchemes = apiKey/privateKey/accessToken）。
- **生成时机**：服务启动期由契约渲染（`custom_openapi(app)` 序列化落盘），先于/并入 help.html 生成钩子。
- **提供方式**：**固定 URL `https://<域名>/static/openapi.json`**（不变），由启动期生成到 `src/api/static/openapi.json` 提供浏览器直接下载；`help/api/openapi.json` 为同内容规范副本（均 .gitignore 生成物）。
- **用途**：开发者/CLI 可直接下载契约做客户端生成、导入 Postman/客户端 SDK。

## 5. 实现路径（内容加载方式）

> 保持「help/ 为唯一事实源」不变；取决于打开页面后目录/内容如何加载。

| 方案 | 做法 | 特点 |
|------|------|------|
| **A. 生成多页静态 HTML（推荐）** | 启动期由 `src/help_page_gen.py` 生成多份静态页：`help.html`（入口）、`usage.html`+`api.html`（壳：完整左目录+空右区），配合按文档生成的独立片段页（或右区章节数据嵌在壳中） | 零 JS 渲染依赖、内网可用、与现有"生成物"模型一致；点目录=页面跳转（整体刷新但左目录仍保留） |
| B. 壳页面 + 内存/接口按需渲染 | help.html 为 JS 壳：入口→区块选择→点击目录项 `fetch` 对应渲染内容，仅替换右区 DOM（无整页刷新） | 体验最贴 docs.gitcode.com（Smooth）；需把渲染源（md→html 片段）以 API/内联 JSON 提供给前端 |

> 若 **B**：右区标记 `data-doc`，目录与内容同源从 `help/` 取；**A** 若仅刷新右区（不整页跳转）则退化为 B——实现前定方案即可，原型不变。

## 6. v1 → v2 差异表

| 项 | v1（现状） | v2（目标） |
|----|-----------|-----------|
| 打开入口 | 直接进入使用指南长页 | 帮助中心入口页，双选项 |
| 使用/API | 同一长页内分隔线拼接 | 两个独立页面/区块 |
| 左目录 | 同时列出 使用指南+API 两组 | 使用页仅使用目录、API 页仅 API 目录 |
| 内容交互 | 整页长滚动，点锚点跳转 | 点击目录仅右区替换渲染，左目录常驻 |
| 章节层级 | 全部章节/小节一列铺开，层级易混 | 同级同缩进树形对齐，小节轻量无框 |
| 框线密度 | 每章/卡片大量边框（长页拼接） | 单文档渲染，仅提示/代码块带框 |
| 契约下载 | 无 | API 文档上方提供 openapi.json 下载（help/api 内，格式同 grape-cli） |
| 导航强化 | 无 | 当前章节高亮 / 折叠 / scrollspy / 搜索 |
