# Spec — Issue #4372 项目场景详情「高级选项」分支选择框支持前缀搜索

- 目标分支：weekly-mys
- 优先级：P2
- 来源 Spec：Issue #4372 评论 203735297（复用，不重复收敛）

## Objective

为「项目场景」详情页「高级选项」的分支选择下拉框（含「新建分支」入口的已有分支参考列表）增加搜索输入与实时前缀过滤，分支较多时可输入即定位，降低滚动查找成本与选错风险。

## Scope

### In Scope

- 「选择已有分支」下拉框顶部搜索输入框，输入即按前缀实时过滤（忽略大小写，占位提示体现规则）。
- 「新建分支」入口的已有分支参考列表复用同一过滤逻辑。
- 无匹配时展示「无匹配分支」空态，不展示空白下拉。
- 仅前端本地过滤，复用 `loadBranches` 已加载的分支列表，不新增后端接口。

### Out of Scope

- 不做模糊/包含/拼音匹配。
- 不改变保存、新建分支链路与后端接口。

## Acceptance Criteria

- [ ] 输入关键字后分支列表实时前缀过滤，忽略大小写，UI 提示明确。
- [ ] 「选择已有分支」与「新建分支」两个入口均可搜索过滤。
- [ ] 无匹配展示「无匹配分支」空态。
- [ ] 选中已有分支保存、新建分支创建及新建后列表回显与现状一致。
- [ ] 新增测试覆盖过滤逻辑（命中/未命中/大小写）。
