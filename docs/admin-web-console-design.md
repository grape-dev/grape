# DevOps Bot Web 管理台 — 设计文档

## 概述

DevOps Bot 需要一个可视化的管理界面，用于配置和管理 Bot 依赖的多账户信息。当前账户配置存储在 `configs/accounts.json` 文件中，包含 GitCode 凭据、飞书应用凭证、华为云 AK/SK 等敏感信息。管理台的目标是让运营人员能通过浏览器安全地查看和编辑这些配置，无需登录服务器直接操作文件。

## 设计目标

1. **配置可视化** — 通过 Web 界面管理多账户配置，替代手动编辑 JSON 文件
2. **账户隔离** — 支持多 GitCode 账户 + 多飞书 App 的组合，每个飞书 App 只能看到绑定的仓库
3. **操作便捷** — 增删改查账户配置，测试 GitCode 连接有效性
4. **安全可审计** — 登录认证，敏感字段脱敏显示

## 用户角色

| 角色 | 权限 | 说明 |
|------|------|------|
| 管理员 | 全部 | 登录后可查看和编辑所有账户配置，添加/删除账户 |

## 功能模块

### 1. 登录认证

- 管理员通过用户名密码登录
- 固定账号：`developer` / `YOUR_SSH_PASSWORD`
- 登录成功后返回令牌，后续 API 请求携带令牌
- 令牌有效期 24 小时

### 2. 账户管理

#### 账户列表

- 以列表形式展示所有已配置的账户
- 每行显示账户名称和 GitCode Token 是否已配置的状态标记
- 支持点击切换查看账户详情
- 支持新增账户

#### 账户编辑

- 表单包含以下字段：

| 字段 | 说明 | 敏感 |
|------|------|------|
| 名称 | 账户唯一标识 | 否 |
| GitCode API Token | 用于调用 GitCode API | 是 |
| GitCode Webhook Token | 用于验证 Webhook 签名 | 是 |
| 飞书 App ID | 飞书应用 ID | 是 |
| 飞书 App Secret | 飞书应用密钥 | 是 |
| 华为云 Access Key | 华为云访问密钥 | 是 |
| 华为云 Secret Key | 华为云秘密密钥 | 是 |
| Bot 用户名 | 逗号分隔的 Bot 账号列表 | 否 |

- 敏感字段输入框为密码类型，前端默认脱敏显示
- 用户修改敏感字段时重新输入完整值，未修改部分自动保留原值

#### 操作

| 操作 | 说明 | 限制 |
|------|------|------|
| 保存 | 新增或更新账户配置 | 名称不能为空 |
| 测试连接 | 用账户的 GitCode Token 调用 `/user` API 验证有效性 | Token 为空时提示 |
| 删除 | 删除账户 | `default` 账户不可删除 |

### 3. 页面布局

```
┌─────────────────────────────────────────┐
│  DevOps Bot 管理台            [退出]    │
├────────────┬────────────────────────────┤
│ 账户列表   │  编辑 default             │
│            │                            │
│  default ✓ │  名称: [____]              │
│            │  GitCode Token: [****]     │
│  [+ 新增]  │  飞书 App ID: [****]       │
│            │  华为云 AK: [****]         │
│            │                            │
│            │  [保存] [测试连接] [删除]   │
└────────────┴────────────────────────────┘
```

- **左侧边栏**：账户列表，可点击切换
- **右侧主区域**：选中账户的编辑表单
- **顶部导航栏**：标题 + 退出按钮

### 4. 响应式适配

- 桌面端（≥768px）：左侧列表 + 右侧编辑，两栏并排
- 移动端（<768px）：单栏布局，列表和编辑上下排列

## 页面流

```
浏览器 → /admin/ → 登录页面
                    ↓ 输入账号密码
                    ↓ POST /api/admin/login
                    ↓ 返回 token
                  管理面板
                    ├─ 加载账户列表（左侧）
                    ├─ 点击账户 → 加载详情（右侧表单）
                    ├─ 修改字段 → 保存 → 更新列表
                    ├─ 测试连接 → 显示结果
                    ├─ 删除账户 → 确认 → 删除
                    └─ 退出 → 返回登录页
```

## 非功能需求

| 需求 | 说明 |
|------|------|
| 安全性 | 登录令牌 24h 过期，敏感字段不在前端明文存储 |
| 可用性 | 操作有 Toast 提示（成功/失败/网络错误） |
| 容错性 | 网络错误显示友好提示，不丢失已填写数据 |
| 可维护性 | 前后端分离，API 独立，前端可独立迭代 |

## 数据模型

### 账户（Account）

```json
{
  "name": "default",
  "gitcode_api_token": "",
  "gitcode_webhook_token": "",
  "feishu_app_id": "",
  "feishu_app_secret": "",
  "huawei_cloud_ak": "",
  "huawei_cloud_sk": "",
  "bot_usernames": []
}
```

- `name` 为账户唯一标识
- `default` 为保留账户，不可删除
- 敏感字段为空时表示未配置
- `bot_usernames` 为数组，存储 Bot 账号名（用于自循环检测）

## API 端点

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/admin/login` | 管理员登录 |
| GET | `/api/admin/accounts` | 获取账户列表（脱敏） |
| GET | `/api/admin/accounts/<name>` | 获取账户详情 |
| PUT | `/api/admin/accounts/<name>` | 创建/更新账户 |
| DELETE | `/api/admin/accounts/<name>` | 删除账户 |
| POST | `/api/admin/accounts/<name>/test` | 测试 GitCode 连接 |

> 所有 `/api/admin/*` 端点需要 `Authorization: Bearer <token>` 请求头。
