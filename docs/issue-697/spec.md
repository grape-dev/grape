# Spec: Issue #697 — 巡检重复判定增加根因对比维度（疑似重复降级 + owner 确认）

> 来源：Issue #697 用户反馈（后台 id 358）| Spec 评级 ready | 目标分支 weekly-mys

## Objective
巡检/反馈分诊的重复判定从「仅标题相似」升级为「标题相似 + 根因对比」双维度；根因不一致时降级为「疑似重复」，经跟踪单 owner agent 确认后方可并入，且级联关闭不自动触发。

## Scope（In）
- 巡检模板指令（autopilot issue_patrol）与巡检执行 prompt 注入根因三要素比对（报错信息/根因描述/涉及命令与参数）。
- 判定分级：完全重复（可自动并入）/ 疑似重复（挂起待 owner 确认）/ 不重复。
- findings/dispatch 结构携带 `dedup_level`/`dedup_note`；疑似重复未确认时派发挂靠被 409 门禁拦截。
- 反馈分诊判重路径（issue summary 注入 prompt）追加双维度判定与级联关闭守护规则。
- 历史误并案例 #446 vs #126、#179、#277 回归验证（fixture 测试）。

## Scope（Out）
- 巡检调度频率/cron 逻辑调整；跨仓库判重；历史误并单批量回滚。

## Acceptance Criteria
- [ ] 巡检重复判定输出包含根因三要素比对结论
- [ ] 仅标题相似且根因不一致 →「疑似重复」不自动并入
- [ ] 疑似重复需 owner agent 确认后才执行挂靠并入（dispatch 门禁）
- [ ] resolve 级联关闭对「疑似重复（未确认）」不自动触发
- [ ] 回归：#446 vs #126、#179、#277 判定为非完全重复
- [ ] 现有测试通过 + 新增测试覆盖判定与门禁
