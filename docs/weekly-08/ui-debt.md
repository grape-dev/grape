## 债项

### 1. 需求中心（issues）整体太黑，细节不清晰
- 范围：issues 列表页 + 详情页（均未迁移，老壳渲染）
- 症状：暗色主题下整体页面太黑，不方便看细节，详情页尤其严重
- 备注：issues(1981行) 在大件队列中，迁移时一并处理暗色层级
- 状态：`[ ]`

### 2. 项目场景（scene）与 IM 渠道页面太白太亮，不符合暗色风格
- 范围：scene-market（已迁移 Vue）、im-channel（已迁移 Vue）
- 症状：暗色主题下这两页反而偏白偏亮，与整体暗色风格不协调
- 疑似原因（待迁移收口后核实）：壳内 Vue 视图的 bridge.css 把 `--glass-bg` 映射到 `var(--c)`（暗色下 #1c1c1e），但视图内部大量硬编码 `rgba(255,255,255,.6)`/`color-mix(var(--c) 72%, transparent)` 的白色系表面未跟随；毛玻璃层在暗色下应该用深色基底+白色低透明度分层，而不是亮色面
- 状态：`[ ]`

### 3. 流水线/Agent运行时/仓库设置页面的小配色太突兀（霓虹感、扎眼）
- 范围：pipeline（已迁移）、runtimes（未迁移 2270行）、repos+settings（壳耦合组，未迁移）
- 症状：各种小配色（状态色点/徽标/强调色块）饱和度过高，像霓虹灯，扎眼
- 方向：暗色下全面降饱和（SRE 空绑定那套"柔和层"经验可复用：prefers-color-scheme 时降饱和已有先例），统一色板
- 状态：`[ ]`

### 4. 场景技能/项目知识库/chat agent 页面配色问题
- 范围：skills（下一批 1058行）、knowledge（未迁移）、chat（未迁移 1422行）
- 症状：配色不协调（主人未展开细节，处理前与主人逐页确认具体问题）
- 状态：`[ ]`

### 5. 运行驾驶舱（dashboard）卡片边界不清晰、突兀
- 范围：dashboard（未迁移 2513行，大件）
- 症状：卡片边界十分不清晰，看起来突兀
- 方向：暗色下卡片边界需要可见的分隔（细描边 rgba(255,255,.08) 或阴影分层），而不是靠背景色差
- 状态：`[ ]`

### 6a. dashboard 场景中心卡片白底在暗色下过亮（2026-10-26 批12验收发现）
- 范围：dashboard 主页/详情页（批12已迁移 Vue，DashboardView.vue）
- 症状：暗色模式下 scn-row/ap-nd/det-card-wrap 等卡片用 rgba(255,255,255,.6) 半透明白底+blur，暗色像素占比仅 37-59%，卡片与深色背景对比刺眼（亮像素 13-17%）
- 定位：老代码同款硬编码（等价迁移带过来），与债项2 同根源
- 方向：卡片底色改 color-mix(var(--c) 62%, transparent)（bridge token 已有 --glass-bg），暗色自动深色基底
- 状态：`[ ]`（与 #1/#2/#6 同批收口处理）

### 6. 需求详情页字体颜色接近背景无法辨别（2026-10-26 批9验收后新增）
- 范围：issues 需求详情页（批9已迁移 Vue，IssuesView.vue 详情卡）
- 症状：详情卡内字体颜色为黑色、接近背景颜色，肉眼无法辨别，影响用户体验
- 定位：IssuesView.vue 详情卡的 label/value 用 `var(--t3,#86868b)`/`var(--t1,#1d1d1f)` 带亮色 fallback；亮色下正常，暗色下若老壳变量未覆盖到则落到 #1d1d1f 近黑字撞深背景。老 _detailHtml 同款内联样式（等价迁移把问题一并带过来了）
- 方向：详情卡样式改走 bridge token（--c-text/--c-text-2/--c-text-3），且 rgba(0,0,0,.02) 卡片底在暗色下换 color-mix 深色基底（与债项2 同根源）
- 状态：`[ ]`（与 #1/#2 同批收口处理）

## 处理原则（收口后批量执行时遵守）

1. **统一在 Vue 侧处理**：所有已迁移/将迁移页面用 tokens.css 的 `--c-*`/`--glass-*` 变量表达，不在视图里硬编码亮色 hex（坑#4 的老规矩）
2. **明暗双生**：每个修复必须双主题截图验收（批4已沉淀正确截图姿势：playwright emulate_media + PIL 像素核对）
3. **逐页验收**：涉及页面多，收口后按页面分小批，每批主人过目
4. 老壳独有页面（未迁移的 issues/runtimes/repos 等）**不单独修**，等各自迁移批顺带处理，避免双份工作量
- #7 admin独立站无暗色主题：tokens.css 无任何暗色变量定义（老版本即如此），登录页固定黑底、主界面恒亮。批17迁移按行为等价保留，双主题截图明暗同图。收口后决定是否给 admin 补 --c-* 暗色变量集
