# 华为云Skill开发场景

华为云技能开发场景，使用 grape 技能框架开发和发布技能包到华为云。

## 技能链路

1. **VOD** — 技能需求分析（vod）
2. **Issue** — 技能任务规划（skill-issue）
3. **Coding** — 技能代码编写（skill-creator）
4. **QA** — 技能测试验证（skill-tester）
5. **SRE** — 技能打包发布（skill-publish）

## 推荐模板

hello-skill — 技能开发脚手架模板

## 适用场景

- grape 技能框架开发
- 华为云技能包发布
- 技能市场贡献
