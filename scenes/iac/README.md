# IaC开发场景

基础设施即代码开发场景，使用 Terraform 管理云资源，适合 DevOps 基础设施团队。

## 技能链路

1. **VOD** — 基础设施需求分析（iac-vod）
2. **Issue** — 基础设施任务拆解（iac-issue）
3. **Coding** — Terraform 代码编写（iac-coding）
4. **QA** — 基础设施代码审查（iac-qa）
5. **SRE** — 基础设施部署（iac-sre）

## 推荐模板

tf-infra — Terraform 基础设施模板

## 适用场景

- 云资源管理
- 基础设施自动化
- DevOps 基础设施团队
