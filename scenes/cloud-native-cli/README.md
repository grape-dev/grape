# 云原生开发场景（CLI 版）

云原生应用开发场景（CLI 版）：面向微服务架构和容器化部署的项目，全程使用 `grape` CLI 命令行操作（`$GRAPE_SESSION_TOKEN` 认证）。

## 技能链路

1. **VOD** — 需求收集与声音分析（vod-cli）
2. **Issue** — 需求拆解与任务规划（issue-cli）
3. **Coding** — 代码实现（coding-cli）
4. **QA** — 代码审查与工作流质量审查（qa-cli）
5. **SRE** — 云上部署（deploy-cli）

## 推荐模板

micro-svc — 微服务脚手架模板

## 适用场景

- 微服务架构项目
- 容器化部署应用
- 云原生应用开发
- 偏好 / 要求全部 Grape 操作走 CLI 命令的环境
