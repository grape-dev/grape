# Agent开发场景

AI Agent 应用开发场景，适合构建智能体应用和多 Agent 协作系统。

## 技能链路

1. **VOD** — 需求收集与声音分析（vod）
2. **Issue** — 需求拆解与任务规划（issue-advance）
3. **Coding** — Agent 代码实现（implementation）
4. **QA** — 代码审查与测试（pr）
5. **SRE** — 云端部署（cloud-deploy）

## 推荐模板

ai-interview-swarm — AI 面试多 Agent 协作模板

## 适用场景

- AI Agent 应用开发
- 多 Agent 协作系统
- LLM 应用开发
