# 通用Skill开发场景（标准API管理）

通用 REST API管理 技能开发场景，使用 “REST API管理” 技能生成器 快速开发和测试技能。

## 技能链路

1. **VOD** — 技能需求分析（vod）
2. **Issue** — 技能任务规划（skill-issue）
3. **Coding** — REST API 技能生成（rest-api-skill-creator）
4. **QA** — REST API 技能测试（rest-api-skill-tester）
5. **SRE** — 技能打包发布（skill-publish）

## 推荐模板

hello-skill — 技能开发脚手架模板

## 适用场景

- REST API 技能开发
- 通用技能包开发
- 技能市场贡献
