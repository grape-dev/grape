chat 路径不调 _build_project_info_section

chat 路径从最初设计（e22dbce7）就不调 _build_project_info_section：
- 没有 baseline 摘要内联
- 没有 member 引导文字
- 只有 _build_agent_knowledge_section 内联 agent 知识

设计如此——chat 是对话场景，agent 做对话/沉淀/流程控制，不需要 baseline 项目背景。
