原型说明

操作 1：清理对话 新增
- 对话面板标题栏"清理对话"按钮
- 点击 → 确认气泡（复用 Chat Agent 样式）
- 确认 → 删 event_thread 记录 → 刷新
- 清理后：对话消息清空，对话产出面板的"流程操作"消失（🔄 记录在 event_thread 里）

操作 2：删除知识 新增
- 对话产出面板改为三个按钮（仓库级 / Issue 级 / Agent 级）
- 按钮显示知识摘要 + 字数
- 点击 → 弹窗展示 markdown 渲染的知识全文
- 弹窗底部"删除"按钮：
  • project 级 → 二次提示"所有 Agent 共享，确认删除？"
  • issue / issue_agent 级 → 直接确认
- 删除后：文件 + DB 记录 + ref 全部清除 → 刷新 → 该按钮消失

两个操作完全独立：清理对话不删知识，删除知识不删对话

知识按钮 新增 替代原来的全文塞入展示
流程操作 已有 清理对话后消失（存在 event_thread 里）
